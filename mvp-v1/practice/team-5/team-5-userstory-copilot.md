# Team 5 User Stories

## User Story 1
**US-101**: 作為專案經理，我希望能在 Jira Dashboard 上即時掌握專案進度的整體視覺化數據，以便能快速發現進度落後的情況並採取行動。

## User Story 2
**US-102**: 作為團隊成員，我希望能在儀表板上查看我的任務狀態和優先級，以便能更有效地規劃每日工作。

## User Story 3
**US-103**: 作為利害關係人，我希望能透過簡單易懂的圖表了解專案進度，以便能對專案進行更好的決策支持。
